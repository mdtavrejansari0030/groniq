Local crawl settings

The limits above are saved when you start an audit. The local workspace uses one concurrent page, at least 0.5 seconds between page requests, and respects robots.txt.

Rendering
HTTP inspects the server response. Chromium inspects rendered HTML and can load page scripts and resources; use it only when needed.
Storage
local-apps/grocrawl/data/users.db. Back up this file with the server stopped. Existing tables and saved crawl IDs are retained.
Export scope
URLs, Links, or Issues from the currently loaded audit. CSV, XLSX, JSON and XML are supported.
Scope
500-page local cap. Sitemap probing, independent external link checks, image fetches and PageSpeed requests are off. Linked URLs are discovered from HTML.
Local authentication
Single local account on a loopback host. This is not a public multi-user deployment.
